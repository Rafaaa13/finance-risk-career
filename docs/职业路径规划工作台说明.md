# 金融与泛体制职业路径规划工作台（公司与岗位版）

直接打开 `index.html`（离线、无依赖）。数据与代码分开，便于逐条更新：

```text
src/data/   公司记录、待核实名录、职业走廊、时间节点（每个文件一个主题）
src/app/    页面逻辑
build.py    把 src 拼成单文件 index.html：python3 build.py
```

## 数据口径

每个数字旁标证据等级：

- E1 官方一手（公告原文、年报、官方接口）
- E2 权威媒体或官方转载
- E3 高校/第三方转载或检索摘要
- ND 未公开或本次未核实（不估算）

综合指数、稳定性、工作节奏、成长性、薪酬上限、目标适配、进入容易度均为判断分（1–5），不是统计结果。WLB 没有找到任何机构的权威公开口径，因此只给“工作节奏”判断。

年报人均薪酬 = 公司层面薪酬项 ÷ 年末员工数，且有三种口径（现金流口径、费用口径、应付职工薪酬口径），不能跨口径比较，也不是校招起薪。

- 15 家有官方披露的 HC；24 家有可复算的年报人均薪酬
- 23 组待核实名录（官方入口已列，数据未核实）
- 23 类岗位族谱、5 条职业走廊、13 个招聘节点

## 更新方法

在 `src/data/` 中按 `add({...})` 的格式追加或修改机构，运行 `python3 build.py`。新增数字必须附官方链接；查不到就写“未核实”。
