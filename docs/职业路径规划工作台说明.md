# 金融与泛体制职业路径规划工作台

> 这是一个职业探索和求职规划工具，不是招聘承诺、薪资保证或投资建议。岗位事实、HC 和招聘时间会变化，申请前请重新核验官方页面。

## 快速开始

直接打开 `index.html`。它是一个独立、离线、中文 HTML 工作台，不需要安装依赖或连接外部 API。

工作台覆盖金融行业、金融基础设施、监管/政策金融、央国企、事业单位、金融科技和泛体制岗位，支持：

- 按岗位族、目标体系、稳定性、WLB、成长性、抗周期、学历门槛和求职难度筛选；
- 在“稳健优先”和“成长/薪资优先”两套目标函数之间切换；
- 查看岗位详情、典型雇主、工作内容、能力要求、学历门槛、HC 证据状态和招聘周期；
- 将岗位加入对比篮子；
- 查看职业路径走廊和单向门提醒；
- 生成基于当前筛选结果的个人下一步行动清单；
- 查看 2027/2028 秋招倒排时间线和来源清单。

## HC 口径

HC 是最容易被误用的字段。工作台不会把“招聘规模很大”“网上很多岗位”伪装成精确 HC：

- `已披露`：官方公告或职位表明确写出计划人数；
- `HC等级`：只有相对规模等级，不能当精确人数；
- `未公开`：机构没有公开可比 HC，工作台明确显示缺口；
- `招聘信号`：来自官方招聘入口、公告频次或公开招聘周期，只能表示机会可见度，不表示真实 HC。

国考可较完整地观察计划招录、报名/过审、进面线和拟录用公示；银行、交易所和央企通常只公开部分计划或岗位，不公开完整报名竞争数据。不要把不同年份、不同口径的 HC 数字直接比较。

## 个人化排序原则

排序默认考虑：稳定性、抗周期性、薪资上限、进入确定性、WLB、成长性、技能可迁移性、简历背书和求职难度。工作台提供两套目标：

- 稳健优先：更看重泛体制、核心控制职能、金融基础设施和抗周期性；
- 成长/薪资优先：更看重金融市场、量化风险、资管、金融科技和可迁移硬技能。

用户背景中的金融本科、跨境教育、银行/审计/券商/互联网/AI 经历，以及 NUS MQF 或 CUHK FinTech 规划，会被转译为“金融业务 + 风险/数据/金融科技”的匹配逻辑；具体个人信息不作为本公开工作台的事实证明。

## 诚实边界

“求职难度”“工作生活平衡”“薪资上限”和“抗裁员性”很少有统一公开统计。工作台中的这些字段是基于岗位属性、公开招聘信号和职业路径推断的比较工具，不是精确概率。岗位详情会标注“官方事实”“相对等级”或“职业判断”。
