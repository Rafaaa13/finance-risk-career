# finance-risk-career

## 公开仓库说明

This repository is a bilingual-adjacent portfolio project for finance-risk career preparation. It combines a Chinese role-selection memo, an evidence-based internship timeline, authoritative source links, and an offline training workbench.

The repository does not claim real trading performance, production risk-model validation, external user impact, or hiring outcomes. The workbench uses synthetic local data and should be treated as a learning and interview-preparation tool.

## Repository map

- `index.html`: offline training workbench entry point.
- `金融风险能力训练工作台.html`: Chinese single-file workbench.
- `docs/岗位推荐与时间线.md`: role ranking and internship timelines.
- `docs/来源清单.md`: regulatory, official recruitment and programme sources.
- `docs/面试与项目证据模板.md`: interview evidence and resume boundaries.
