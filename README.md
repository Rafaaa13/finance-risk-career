# 金融风险岗位求职与能力训练工作台

> 面向风险管理、模型验证、金融基础设施、金融科技、ALM/固收和反洗钱方向的岗位选择、能力训练与面试证据项目。

这个仓库把三件事情放在一起：一是基于公开监管文件、金融机构官方招聘公告和项目官网信息整理的岗位选择建议；二是一个可以直接打开的离线金融风险能力训练工作台；三是一个覆盖金融行业与泛体制岗位族的职业路径规划工作台，用于比较岗位门槛、HC 口径、稳定性、WLB、成长性和职业转移。

## 快速开始

不需要安装依赖。直接打开 [`index.html`](index.html)，或打开同目录下的 [`金融风险能力训练工作台.html`](金融风险能力训练工作台.html)。

推荐训练顺序是：

```text
训练总览
  → 八周路线图
  → 风险实验室
  → 金工计算台
  → SQL 数据练习
  → 本机练习
  → 项目证据包
  → 面试演练
```

工作台包含离线合成贷款组合、PD/LGD/EAD 与 Expected Loss、压力测试、Black–Scholes、Greeks、Monte Carlo、SQL 查询、Python/SQLite starter、项目证据包、90 秒面试口述稿和训练进度 JSON 导入/导出。

## 重要边界

工作台使用本地生成的合成数据，训练结果不代表真实借款人行为、真实投资业绩、金融机构生产系统或监管验证结果。只有在你本人独立运行代码、完成本机练习、保存输出并能够解释输入、方法、结果和局限后，才可以把相应内容写入简历；不要把“使用过工作台”写成“拥有生产经验”。

仓库中的岗位建议是职业规划参考，不构成招聘承诺、投资建议或对具体机构工作生活平衡和裁员概率的保证。

## 职业路径规划工作台

直接打开 [`职业路径规划工作台.html`](职业路径规划工作台.html)。它覆盖 27 个金融与泛体制岗位族，支持岗位体系/关键词/学历/HC 口径筛选，稳定优先与成长/薪资优先排序，岗位详情、最多 4 个岗位族对比、风险/固收/数据与AI/政策四条职业走廊、秋招倒排和来源账本。

职业路径工作台和金融风险能力训练工作台相互独立：前者用于选择岗位和规划路线，后者用于训练技能和沉淀项目证据。

## 岗位推荐摘要

综合稳定性、成长性、薪资上限、工作生活平衡、抗周期性、技能可迁移性和简历含金量，下一段实习优先级建议为：

| 优先级 | 岗位族 | 重点训练能力 |
| --- | --- | --- |
| 1 | 风险管理、风险计量、模型风险、风险科技 | PD/LGD/EAD、压力测试、模型验证、Python/SQL、风险解释 |
| 2 | 金融基础设施、清算、数据治理、监管科技 | 数据字典、点时口径、来源血缘、清算/市场运行风险 |
| 3 | ALM、资金、市场风险、固收风险、保险资管风险 | 利率风险、流动性、久期、凸性、DV01、资产负债匹配 |
| 4 | 反洗钱、金融犯罪合规、交易监测模型 | 客户尽调、可疑交易、风险规则、合规数据分析 |
| 5 | 金融机构内金融科技、数据产品和风险系统 | 业务需求、数据治理、风险系统、产品落地 |

不建议把纯投行、纯股票研究、PE/VC、银行分行营销、泛战略、泛互联网产品或小型金融科技增长岗作为主路线，除非岗位内容和你的目标方向高度匹配。

## 你的背景如何接上这条路线

你已有金融本科、KEDGE 双学位、工行/安永/光大证券/滴滴/百度等经历。下一段实习最需要补的是一条清晰的“金融业务 + 风险管理 + 数据/金融科技”主线，而不是继续堆叠泛产品或泛战略标签。

更理想的简历叙事是：

```text
金融本科与跨境背景
  → 证券/审计/互联网与 AI 产品经历
  → 风险计量、金融数据治理或金融基础设施实习
  → 金融工程/金融科技硕士
  → 风险管理、模型验证、金融科技或金融基础设施岗位
```

## 实习时间线

### 如果硕士第一年参加秋招

```text
2026.10—2027.04/06  一段 4—6 个月的金融核心实习
                    优先：风险计量/模型风险/风险科技/金融基础设施/ALM/固收风险
2027.03—2027.06     必要时补一段短而硬的金融数据或模型项目
2027.07—2027.08     完成英文金融简历、Python/SQL 项目和面试证据包
2027.09—2027.10     硕士第一年秋招：投风险、金融科技、金融基础设施与金融市场岗位
```

### 如果硕士第二年参加秋招

```text
2026.10—2027.06  做一段 6—8 个月的风险/金融科技/金融基础设施锚点实习
2027.08—2028.06  结合硕士课程选择金融工程、金融科技或风险实习
2028.06—2028.08  争取一段有正式项目和留用可能的高质量暑期实习
2028.08—2028.10  用两段金融核心经历和一个可复现项目参加秋招
```

## 如何判断一份实习值得去

面试时要问清楚：你属于哪个部门和岗位族；是否会使用 Python/SQL；能否接触真实业务数据；实习生交付物是什么；能否向主管汇报；团队是否有正式招聘 headcount；岗位是核心部门自招还是外包/派遣；加班主要发生在什么节点。

如果岗位只能描述为“协助老师完成日常工作”“整理材料”“配合部门安排”，却无法说明项目、数据、工具和交付物，就不应该因为机构 logo 而自动排在前面。

## 使用建议

先完成一次风险实验和一次 SQL 查询，再进入项目证据包。之后在本机下载 starter 文件，独立运行 Python/SQLite，保存终端输出和错误修复记录。最后用面试演练回答：为什么用 Expected Loss、压力因子如何设定、合成数据有哪些局限、如何验证结果不是样本结构造成的。
